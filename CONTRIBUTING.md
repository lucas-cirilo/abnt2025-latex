# Contribuindo com o abnt2025

Obrigado por considerar contribuir com o pacote `abnt2025`! Siga as orientações abaixo para colaborar de forma eficiente:

## Como contribuir

1. **Fork este repositório** no GitHub.
2. **Crie uma branch** para sua contribuição:
   ```bash
   git checkout -b minha-contribuicao
   ```
3. **Faça suas alterações** (correções, adições de modelos, melhorias no estilo, etc).
4. **Commit suas mudanças** com uma mensagem clara e descritiva.
5. **Envie um Pull Request** para o repositório original.

## Boas práticas

- Sempre mantenha a compatibilidade com as normas ABNT vigentes.
- Teste o exemplo antes de submeter.
- Prefira escrever em português para manter a consistência do projeto.
